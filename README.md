# AliOS: Retro Desktop Operating System and Portfolio

**AliOS** is a Windows 95/98 style interactive web operating system built with **React**, **TypeScript**, and **CSS**. It serves as a personal portfolio and runs inside the virtual CRT monitor of the [portfolio-website](https://github.com/mohammadali-2000/portfolio-website) 3D room.

## Features and Changes in this Fork

* Draggable, resizable, and minimizable retro Windows 95 style windows.
* Integrated Dangerous Dave (1990) playable in browser via js-dos WebAssembly emulation.
* Cleaned up application list to focus on core showcases and retro gaming.
* Updated career profile, projects, and work history for Syed Mohammad Ali (Accenture, MPSeDC).
* One click resume PDF viewer and downloader.
* Responsive event bridge with the parent 3D Three.js scene.

## Tech Stack

* React 18
* TypeScript
* CSS Modules and Vanilla CSS
* js-dos (WebAssembly DOSBox)

## Development Setup

### 1. Install Dependencies
```bash
git clone https://github.com/mohammadali-2000/portfolio-inner-site.git
cd portfolio-inner-site
npm install
```

### 2. Run Locally
```bash
npm start
```
Runs at `http://localhost:3000`.

### 3. Build for Production
```bash
npm run build
```
